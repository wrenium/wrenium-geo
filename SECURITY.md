# Security Policy

## Supported Versions

wrenium-geo is pre-1.0; only the latest release on `main` is supported.

## Reporting a Vulnerability

Please report security issues privately via
[GitHub's private vulnerability reporting](https://github.com/wrenium/wrenium-geo/security/advisories/new)
rather than a public issue.

This is a solo-maintained project without a dedicated security team --
there is no guaranteed response SLA, but reports are triaged as soon as
possible and a fix or mitigation is prioritized over other work once
confirmed.
